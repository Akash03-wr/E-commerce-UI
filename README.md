# E-Commerce Web Application UI Clone

A responsive, multi-page frontend replica of an e-commerce platform inspired by Amazon, developed with semantic HTML5 and modern CSS3.

## 🚀 Live Demo
- **Live Preview:** [View Live Deployment](https://e-commerce-ui-teal-iota.vercel.app/)

---

## 📌 Project Overview
This project focuses on structuring complex, real-world layout architecture using pure frontend fundamentals. It features a complete multi-page user browsing workflow, custom navigation bars, categorized product grids, and authentication screens.

---

## ✨ Features
- **Multi-Tier Navigation:** Search bar, department menu, delivery location triggers, and cart indicators.
- **Categorical Layouts:** Structured product cards and promotional banners using CSS Flexbox.
- **Multi-Page User Flow:**
  - `index.html`: Main storefront and browsing layout.
  - `location.html`: Modal/interface for selecting delivery regions.
  - `language.html`: User preferences for localized language selection.
  - `login.html`: Styled sign-in screen with form state styling.
- **Responsive Architecture:** Built with clean, maintainable modular CSS.

---

## 🛠️ Built With
- **HTML5:** Semantic document structure across 4 dedicated pages.
- **CSS3:** Modern styling, Flexbox layout design, and interactive form states.
- **Hosting:** Deployed on Vercel.
